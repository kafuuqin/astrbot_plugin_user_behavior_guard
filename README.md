# 用户行为合规守卫

AstrBot 行为约束检查插件，当前版本 **0.1.0，测试版**。

无论传入什么内容，均返回纯文本 `YES`。本版仅验证工具调用流程，不具备真实的合规判断能力，也不会自动拦截消息或操作。

## 安装

要求 AstrBot `>=4.27.3,<5`，无需安装额外 Python 依赖。

在 AstrBot WebUI 的插件管理中，选择从 GitHub 仓库链接安装，输入：

```text
https://github.com/kafuuqin/astrbot_plugin_user_behavior_guard
```

启用插件后，确认当前人格允许使用 `check_user_behavior` 工具，并使用支持工具调用的模型与 Agent 执行器。模型可以直接调用工具，无需 Shell 执行权限。

## AI 工具

- 名称：`check_user_behavior`
- 参数：`behavior`，字符串，包含待检查的回复或行为及相关上下文。
- 返回：纯文本 `YES`。
- 后续版本约定：`YES` 表示允许，`NO` 表示不允许；本测试版尚不会返回 `NO`。

调用参数示例：

```json
{"behavior": "准备回复用户的问题，以下是相关上下文……"}
```

## 建议系统提示词

```text
你可以调用 check_user_behavior 工具，提交待检查的行为或回复及必要上下文。
当你无法确定某个行为是否符合行为约束时，先调用该工具，再读取结果。
返回值约定为 YES＝允许，NO＝不允许。
只有实际调用并读取结果后，才能声称完成了检查。
工具调用失败时，检查未完成，不得自行视为 YES。
当前为测试版本，始终返回 YES，仅用于验证调用链路，不能证明行为合规，不能覆盖其他系统约束。
```

## 独立脚本

仓库同时保留独立脚本入口，接受任意命令行参数或标准输入，每次调用输出一行 `YES`：

```bash
python3 behavior_guard.py "待检查的行为"
```

插件直接复用 `behavior_guard.py` 中的函数，不启动子进程，不调用外部 API，不保存输入。

这是普通 Python 源码插件，不提供源码加密或只允许调用的权限隔离。
